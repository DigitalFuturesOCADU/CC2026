Experiment 2 · One Phone, More People

Eight examples. Motion, touch and sound go in. The screen, sound and the flashlight come out. Each one has a version for 1, 2 and 3 people sharing one phone. The output is the same in all three. Only the number of people changes, so try all three and compare. On a laptop, each sketch shows a QR code to open it on a phone.

  • 01 Tilt to DrawMotion → screen. In turn: the phone is passed every 15 seconds, and each person draws in their own colour.
    • 1 person code web editorTip the phone to steer the pen. One line, one colour.
    • 2 people code web editorDraw for 15 seconds, then pass the phone when the colour changes. Two colours build up on one drawing.
    • 3 people code web editorThe phone goes around three people, 15 seconds each. Three colours on one drawing.
  • 02 Tilt to SpeedMotion → sound. In turn: one recording loops, and each person gets their own copy of it, their own voice.
    • 1 person code web editorTilt to bend the speed of the loop. Flat is slow, upright is fast.
    • 2 people code web editorSet a speed and pass the phone. Your voice keeps playing while the second person bends a second voice against it.
    • 3 people code web editorThree voices at three speeds. When the phone comes back around, you change your own voice again.
  • 03 Still for LightMotion → flashlight. Together: the light comes on when the phone has been still for a second. The code is the same in all three.
    • 1 person code web editorRest the phone face down on your palm. Hold still and the light comes on.
    • 2 people code web editorTwo people hold the phone up together on their fingertips. It stays lit only while both are steady.
    • 3 people code web editorThree people on their fingertips. The light shows how still three people can be together.
  • 04 Hold to RevealTouch → screen. Side by side: one strip of the screen for each person. A finger on your strip shows your part of the picture.
    • 1 person code web editorHold a finger anywhere and the whole picture fades in.
    • 2 people code web editorOne half each. The whole picture shows only when both of you are touching.
    • 3 people code web editorOne strip each. Each person shows a third. The whole picture needs all three.
  • 05 Hold a NoteTouch → sound. Side by side: one strip for each person, one note for each strip. Slide up for higher, down for lower.
    • 1 person code web editorOne strip, one note. Hold to play it, slide to change it.
    • 2 people code web editorTwo notes. Each person moves their own, and you both hear the two together.
    • 3 people code web editorThree notes: a chord made by three people.
  • 06 Hands for LightTouch → flashlight. Together: the light blinks faster with each finger on the screen, and stays on when everyone is touching.
    • 1 person code web editorTouch the screen and the light turns on. Let go and it turns off.
    • 2 people code web editorOne finger makes a slow blink. It stays on only when both of you are touching.
    • 3 people code web editorOne finger: a slow blink. Two: faster. All three: steady on.
  • 07 Hum to PlaySound → screen. Together: the robot runs while there is sound and freezes in silence. The code is the same in all three.
    • 1 person code web editorHum and it runs. When you stop for breath, it freezes.
    • 2 people code web editorTwo people hum, overlapping their breaths so it keeps running.
    • 3 people code web editorThree people hum in a relay. With three, it never has to stop.
  • 08 Quiet for LightSound → flashlight. Together: the light comes on after three seconds of silence, and any sound turns it off. The code is the same in all three.
    • 1 person code web editorBe quiet for three seconds and the light comes on.
    • 2 people code web editorThe light needs both of you to be quiet.
    • 3 people code web editorThe light comes on only when all three of you agree to be silent.

Phone Basics · p5-phone

The pattern every phone sketch uses: lock the gestures, ask on a tap, check the flag, then read.

  • 01 Start Here code web editorThe blank phone sketch. Lock the gestures, ask on a tap, wait for the flag.
  • 02 Debug Panel code web editorA phone has no console. showDebug() puts one on the screen.
  • 03 One Tap, Many Permissions code web editorMotion, microphone and flashlight from one tap, then a check of each flag.

Input · Motion

Tilt, shake and movement. The values are p5.js's own: rotationX, accelerationX, deviceShaken().

  • 01 Tilt code web editorrotationX and rotationY move a circle.
  • 02 Shake code web editordeviceShaken() is an event. Each shake picks a new colour and adds one to a count.
  • 03 How Much Movement code web editorAcceleration, added up and smoothed: how much the phone is moving.

Input · Sound

The microphone: how loud, when it gets loud, and how high or low.

  • 01 Level code web editorHow loud it is, from 0 to 1, sets the size of a circle.
  • 02 Clap code web editorA loud moment is an event. Each clap counts once.
  • 03 High and Low code web editorThe FFT splits sound into bands. Low and high each get a bar.

Input · Touch

Where the fingers are, how many there are, and which part of the screen they hold.

  • 01 Where code web editormouseX and mouseY follow a finger. mouseIsPressed says if one is down.
  • 02 How Many code web editortouches holds every finger on the screen. Count them, draw them. Phone only: the mouse is not a touch.
  • 03 Zones code web editorThe screen in three parts. Each part lights while a finger holds it. Phone only.

Output · Drawing

Shapes, trails and repeats, drawn on the screen.

  • 01 Shapes code web editorbackground, fill, circle, rect, line and text, redrawn every frame.
  • 02 Trails code web editorTilt steers a pen. A see-through background leaves a fading trail.
  • 03 Repeat code web editorA for loop draws a ring of shapes. A finger sets how many.

Output · Images

Load an image, fit it to the screen, and change it with input.

  • 01 Load and Fit code web editorawait loadImage(), then image() as big as fits the screen.
  • 02 Tilt to Scale code web editorTipping the phone forward and back scales the image.
  • 03 Shake for the Next code web editorA list of images. Each shake shows the next one.

Output · GIFs

A GIF is an image with frames. Play it, pick a frame, change its speed.

  • 01 Play and Pause code web editorThe GIF plays while a finger is down and pauses when it lifts.
  • 02 Tilt to Frame code web editorTilt picks the frame with setFrame(). The GIF never plays on its own.
  • 03 Speed code web editordelay() sets the time between frames. A finger sets the speed.

Output · Sound

One example for each way of making sound: a recording, a tone, a loop, an instrument, a voice.

  • 01 Play a Recording code web editorp5.sound. A quick tap starts and stops a loop. Hold and slide to bend its speed.
  • 02 Make a Tone code web editorp5.Oscillator. A tone sounds while a finger is down. Left to right is low to high.
  • 03 Start a Loop code web editorTone.js. A pattern of notes on Tone.js's own clock. A tap starts and stops it. A finger sets the tempo.
  • 04 Play an Instrument code web editorsmplr. A marimba made of recordings. The screen is the keys.
  • 05 Say Something code web editorThe browser's own voice. A tap says the next word.

Output · Flashlight

The camera's light, switched by the sketch.

  • 01 Tap for Light code web editorA tap switches the flashlight on and off.
  • 02 Slow Blink code web editorA timer blinks the light. Tilt sets how slowly, never faster than 300 ms.

Connecting Input to Output

The small moves between a sensor and an output: map, smooth, threshold, fade, combine.

  • 01 Map code web editormap() turns tilt in degrees into screen brightness.
  • 02 Smooth code web editorlerp() smooths a jumpy reading. Raw and smoothed side by side.
  • 03 Threshold code web editorA stream becomes an event: tipping past a line counts once.
  • 04 Fade code web editorAn event starts a clock. The light fades over three seconds.
  • 05 Combine code web editorTwo inputs at once: the light needs a finger down and the phone tipped.
